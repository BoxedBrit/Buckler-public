# Buckler Public

Public issue tracker and feedback repository for **Buckler**.

This repository exists so users, testers, and server owners can report issues, suggest improvements, and give feedback for Buckler services without exposing the private source repositories.

## Security

Do not report vulnerabilities publicly.

Use:
support@buckler.gg

> [!IMPORTANT]
> This is a public support and issue-tracking repository only.
> The core Buckler source code is not hosted here.

## What can be reported here

You can open issues for:

- **Website** issues
- **Dashboard** issues
- **API / backend** problems
- **Game mod/plugin** bugs
- **Documentation** issues
- **Feature requests**
- **Performance concerns**
- **UI / UX feedback**

## What this repository is for

This repository is intended for:

- bug reports
- feature requests
- support-related issue tracking
- public-facing project updates or documentation

## What this repository is not for

Please do **not** use this repository for:

- private security vulnerabilities
- account recovery
- billing or personal data issues
- confidential server information
- sharing secrets, tokens, IPs, database details, or private logs publicly

For sensitive matters, contact via support@buckler.gg or use the contact form located on Buckler.gg/contact

## Before opening an issue

Please:

1. Search existing issues first
2. Use a clear title
3. Select the correct service area
4. Include steps to reproduce
5. Include version numbers where relevant
6. Attach logs, screenshots, or clips if helpful
7. Remove any sensitive information before posting

## Service areas

When opening an issue, please identify the affected service:

- Website
- Dashboard
- API / Backend
- Game Mod/plugins
- Documentation
- Other

## Helpful information to include

Depending on the issue, useful details may include:

- Buckler version
- Mod/plugin version
- Minecraft version/Game version
- Loader/platform version
- Browser and browser version
- Operating system
- Server software
- Reproduction steps
- Expected behaviour
- Actual behaviour
- Screenshots
- Relevant logs

## Feature requests

Feature requests are welcome. Please explain:

- the problem you are trying to solve
- your suggested solution
- any alternative approaches considered
- why it would be useful

## Security

Please do **not** report security vulnerabilities in public issues.

If a report involves exploits, authentication bypass, data exposure, token leakage, or anything security-sensitive, report it privately instead.

## Status

Buckler is under active development. Some areas may change rapidly during testing.

Thanks for helping improve Buckler.
